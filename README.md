# 汉字音典 iOS

数据直接来自 osfans/MCPDict 的 GitHub 规范化字表，在 iPhone 本地建立查询索引，不读取或提取 APK。当前目标是验证 iPhone 安装、分类目录、独立字表下载和离线查询，并非 Android 版完整复刻。

当前版本 0.5：App 显示名为“汉字音典”。加入字体滑杆、七种调类与三种调值显示、两套分区配色、任意层级整区选择和读音包含搜索；地图标签常驻，支持字形切换、三种系统底图和已安装地图 App 跳转。0.4 的下载／移除分开、取消后保存已完成字表、简繁界面继续保留。

0.2 功能继续保留：复用安卓图标；汉字查询只显示所查字；查询语言列表支持三种分区；底部设置可选浅色、深色或跟随系统。实际验证以对应提交的 Actions 和 VALIDATION.md 为准。

## 安装到 iPhone

支持 iOS 17+，本次目标为 iPhone 13 / iOS 26。到本仓库 Releases 选择最新 iPhone development build，下载 MCPDict-iPhone-unsigned.ipa。IPA 未签名，须通过 Windows AltServer / AltStore Classic 使用自己的 Apple 账号签名安装，不能在 Safari 下载后直接点开。详见 [INSTALL-IPHONE.md](INSTALL-IPHONE.md)。

## 不内置字表

首次安装没有词典内容。进入「字表」取得小型目录，勾选语言点后点击「字表下載」。目录直接读取安卓上游 master 的 tools/tables/output/_詳情.json 与 Git 文件清单。本次验证的目录包含 3,308 份有元数据的 TSV 字表；不包含通用汉字/字书基础库。

支持地图集二分区、音典分区、行政区划（省、市、县、镇、村等逐级选择）以及语言点名称检索。可以选取一个分类的全部字表，也可单独选择某表。分类只是同一字表的不同入口，稳定 ID 去重，不会重复下载。

勾选语言点后，「字表下載」只下载／更新这些项，保留其他已安装字表；「字表移除」只移除勾选的已安装项。操作栏在二级、三级及更深页面始终显示。字表列表顶部只显示网上与本地字表数量。

取消下载后停止后续下载，保存已完成校验的字表并建立查询索引；未完成的当前字表会丢弃。保存期间请保持 App 开启。原有未选择的字表和收藏不受影响。下载错误也会保留此前完成的字表，并显示错误。

点击查询结果、字表列表或地图中的语言点名称查看档案。展示限定为三组：地点与统计；录入／维护／版本／来源／质量；解析日志。各行“标签：内容”横排，组间留空。档案缓存仍保留完整元数据，旧版缓存首次需联网刷新。

统计优先使用上游字段，缺失时计算本地已下载字表的字数、□ 数、音节数和不带调音节数；未下载则提示下载后统计。上游目录未提供原始解析日志时明确显示“未提供”，不将本地猜测当作原始日志。源文件存在于同一 Git 提交时提供其链接，否则仅显示文件名。

汉字查询按输入顺序优先列出原字，再列出简繁／异体字关联选项。各字形分开显示，每个语言点的多音和注释集中在同一组。汉字模式读取全部匹配行；读音搜索使用原始字符串包含匹配，前缀匹配优先，其次内部包含匹配，分页稳定；注释保留 FTS 检索。

字形数据来自 osfans/MCPDict 的 mcpdict.異體字 字段，与安卓版 DB.java 和网站后端采用相同来源。资源包含 46,257 个有直接关联的字形、73,912 条双向关联。补齐双向关系，不作传递闭包，避免通过多义简化字将不同意义的字一概合并。未知字保留原字；覆盖范围取决于上游登记，不能保证涵盖全部历史异体。它是小型字形索引，不包含方言读音字表，离线可用。

设置中的简繁选项只转换界面文字，原始汉字、读音、注释、作者姓名等来源资料不改写。语言点和区域搜索支持简繁输入。字体滑杆影响语义字体和地图标签。语言点标签与注释同为 subheadline 字号。

声调按照各语言点档案中的“聲調”对照表显示，支持拼音数字、八声、四声、汉字、四角、上下并排与隐藏；调值可选曲线、数字、隐藏。“并排”与网站一致，上排数字调值、下排调类。无登记声调的读音保持原样。数据库与收藏中的原始音标不变。

## 数据与稳定性

App 每次检查更新先读取上游 master 最新提交，再从同一固定提交取得目录和所选 TSV；不会混用更新前后的版本。下载直接访问 raw.githubusercontent.com/osfans/MCPDict，不依赖本仓库发布字表包。上游原始 data 文件需要先由上游生成 output；App 跟随已提交的 output，不在手机运行上游 Python 转换器。

「字表 → 更新目錄」检查最新目录；勾选需要更新的字表后点击「字表下載」。更新按需触发，不是后台推送。GitHub 限流或网络不可用时显示错误，现有字表继续离线可用。

下载校验 Git blob SHA-1 与文件大小，解析 TSV 后建立临时 SQLite 索引，再原子切换本地指针。缓存以字表内容哈希识别，内容未变则复用；下载或解析中断会保存此前完整校验的字表；索引提交失败保留旧索引。兼容旧试验版的 SQLite 安装索引，首次更新会转为上游 TSV。

当前同时保存独立字表数据库和合并查询库，占用大于原始 TSV；操作前保守检查约十二倍所选原始字表大小加 30 MB 空间。下载需保持 App 在前台，有字表级进度和取消，没有后台下载或字节百分比。上游简称变化视为新字表；一键更新遇到已移除字表会要求用户手动确认选择。

## 语言地图

底部「地圖」从字表档案「經緯度」读取经度、纬度。目前 3,308 份表中 3,295 份有有效坐标；缺失或超范围坐标不猜测、不放点。坐标按上游原值显示，没有独立核定坐标基准或测绘精度。

地图检索分“语言／自选／分区／行政区”四类；分区和行政区支持逐级进入并选择当前整区，自选可跨区多选。行政区可切换地图集二或音典颜色。名称和各级区域均可搜索。

点位使用带上游颜色的圆角名称标签，读音直接放在标签下，设置 required 显示优先级，不聚合，不因缩放或未选中而隐藏。密集标签会重叠，需放大或缩小筛选范围；不通过移动坐标做避让。点击名称打开详情，点击读音复制原始音标。单字查询也提供简繁／异体字选项，切换后分别查看已下载字表中的读音。全览按钮缩放到当前点位。

首次需要联网获取目录，不必下载字表内容。目录会缓存，重启可继续显示点位；底图需联网，不提供离线瓦片包。

App 内底图使用 Apple MapKit，支持标准、卫星和混合，在地图工具栏及设置中切换。外观跟随 App 浅色／深色设置，不需要 MapTiler key。

通过地图工具栏可将当前中心交给外部地图 App，字表详情也可打开该语言点。检测已安装的 Apple、高德、百度和 Google Maps；其它 App 使用系统“分享位置”入口，是否列出取决于接收方的分享支持。iOS 不提供任意枚举已安装地图 App 的接口，也不允许读取其它 App 的离线地图文件；外部地图是跳转打开，不是替换音典内的底图或带走全部语言点图层。坐标按原始经纬度传出，外部接口以 WGS84 参数请求，不做未经核实的源坐标转换。

地图与声调显示参考 vearvip/mcpdict-frontend；原生 Swift 重写，保留 App/Frontend-LICENSE.txt。字形来源和构建提交记录于 App/VariantData/variants-source.json，保留 App/Upstream-LICENSE.txt。

## GitHub Actions

- Check iOS and Python：Python 测试、工程生成、iOS 编译与模拟器 XCTest。
- Build iPhone IPA for local signing：真机编译，检查 Mach-O 的 arm64/iOS 平台，打包并发布待本地签名 IPA。
- Build dictionary from GitHub source：构建并验证上游整库，发布清单和源数据诊断。
- Publish experimental downloadable tables：从已验证整库提取三份独立字表，发布包和目录。

代码推送会运行 iOS 检查，App 或真机打包文件变化会生成新的真机包。数据和目录工作流支持手动运行，也在各自构建文件变更时运行，尚未启用每天定时更新。旧整库与三表目录工作流保留作开发工具；当前 App 更新直接连接上游，无需运行这些工作流。

首次基础版本的 [成功记录](https://github.com/ghehyoein/MCPDict-iOS/actions/runs/41994679817)。后续按需下载版本以 Actions 对应提交为准。实际验证范围见 [VALIDATION.md](VALIDATION.md)。

## 编辑应用图标

直接编辑 `tools/AppIcon.png`，建议使用 1024 × 1024 不透明 PNG。构建脚本会复制到 Xcode 资源目录，并在 macOS 调整至标准尺寸。不要编辑生成的 App/Assets.xcassets 图标文件；它会在构建时覆盖。

## Python 优先

Python 负责数据构建、字表拆分、目录清单、参考查询、Windows 测试界面、安卓图标资源准备、IPA 验证和打包。Swift 负责 iPhone 原生界面、SQLite 查询、下载与数据切换。手机内不嵌入 Python 解释器。

Windows 安装 Python 3.12+ 后可运行：

```powershell
py -3 -m unittest discover -s tools -p "test_*.py" -v
py -3 tools/preview.py sample-data/mcpdict.db
```

Windows 界面是独立的完整开发快照查字工具，不代表 iOS 的下载界面。本地工程目录附有快照，Git 仓库不提交大型数据库。

手动构建完整数据（在 Python 虚拟环境中）：

```text
git clone https://github.com/osfans/MCPDict.git data-build/upstream
python -m pip install -r tools/requirements-build.txt
python tools/data_pipeline.py --checkout data-build/upstream --repository ghehyoein/MCPDict-iOS --output dist
```

上游构建可能报告源文件缺失或格式警告，生成成功不代表资料无误。字表来源和许可需要独立核对，上游 MIT 代码许可证不自动覆盖全部数据。

## 功能边界

基础汉字、多字、Unicode、原始读音与注释查询、语言筛选、分页、收藏、笔记和按需字表管理已写入。

尚未移植：繁简/异体字、复杂音韵/拼音转换、形码/部首/笔画、字书详情、矩阵、离线地图、猜字/猜方言、扩展字体、收藏导入导出。行政分类是字表选择入口，不是离线地图。

真机签名、安装和使用效果仍需在你的 iPhone 上确认。当前是开发测试包，不是 App Store 或 TestFlight 成品。

## 更新离线字形索引

从 osfans/MCPDict 固定提交构建完整开发数据库后运行（不会打包完整数据库）：

```powershell
py -3 tools/export_variants.py sample-data/mcpdict.db App/VariantData --commit <上游提交SHA>
py -3 -m unittest discover -s tools -p "test_*.py" -v
```

提交生成的分片与来源清单后，下一版 App 携带新索引；字形索引目前随 App 更新，语言点字表仍独立直接从上游 GitHub 按需更新。
